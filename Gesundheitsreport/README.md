## Gesundheitsreport

**Ziel des Projekts:**  
Analyse von Patientenzahlen, Aufenthaltsdauer und Stationsauslastung zur Unterstützung von Personal- und Kapazitätsplanung im Gesundheitswesen.

**Vorgehensweise:**  
- Analyse der Anzahl aufgenommener Patienten pro Monat  
- Berechnung der durchschnittlichen Aufenthaltsdauer  
- Auswertung der Auslastung pro Station  

**Verwendete SQL-Konzepte:**  
GROUP BY, Aggregationen, CASE WHEN, Datumsfunktionen  

**Nutzen für Pflegeeinrichtungen:**  
Die Analyse unterstützt eine bessere Dienstplanung, Ressourcenverteilung und Qualitätssicherung.
